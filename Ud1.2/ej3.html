Ficha técnica: Visual Studio Code

Información general

Visual Studio Code es un editor de código fuente utilizado para desarrollar aplicaciones y páginas web.

Es un IDE ligero y ampliable mediante extensiones.

Características

Permite escribir código HTML, CSS, JavaScript y otros lenguajes.

Para guardar un archivo se puede utilizar el siguiente comando de teclado:

Ctrl + S

El editor puede utilizarse para desarrollar aplicaciones de diferentes tamaños y complejidades.

Visual Studio Code se publicó por primera vez en 2015, el 29 de abril de 2015.

Versión

Versión de referencia: v1.0th.
